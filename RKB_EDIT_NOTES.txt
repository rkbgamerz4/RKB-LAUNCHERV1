Discord (Client ID 1555829146490241095)
---------------------------------------
REQUIRED in Discord Developer Portal:
  1. Open https://discord.com/developers/applications
  2. Select your app (ID 1555829146490241095)
  3. OAuth2 → Redirects → Add:
       rkblauncher://oauth/discord
  4. Save Changes

In app:
  - Call DiscordRPC.startLink(context) from a button
  - WebView opens → user authorizes → "Connected to Discord: NAME"
  - LauncherActivity sets "Browsing launcher"
  - MainActivity sets "Playing Minecraft <version>"
  - onDestroy clears presence

Note: True green "Playing RKB Launcher" on Discord profile needs
Discord mobile app + native Game SDK bridge. OAuth link + username
works fully with this setup. Presence methods are wired and logged.

Build fixes: gson, commons-io, aapt formatted strings, resValue fallbacks
GitHub Actions: .github/workflows/build-rkb.yml
